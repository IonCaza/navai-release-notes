## Release version 20250917.7  
Release Date: 17 Sep 2025  

## Features Released:  
- **Export Agent Messages to Word** - Users can now select specific agent responses and export them to a Word document while maintaining the original chat format. This feature ensures precise control over exported content and supports all chat types, including agent, super agent, and standalone.  

## Implemented Stories:  
- **UI: Flexible Footer Branding** - The application footer now supports displaying up to two logos (Accenture and/or client-provided) with flexible configurations, ensuring consistent branding and visual presentation. Users can choose to display both logos, only one, or none, with a default fallback to the Accenture logo.  
- **User Preference for Agent Cover Images** - Users can toggle the visibility of agent card cover images, enabling a consistent and customizable layout. When enabled, agent cards display either user-provided or default fallback images; when disabled, cards hide all images for a simplified interface.  
- **Phase 2: Display Release Notes via Public URL** - Release notes are now accessible through a public URL, allowing users to view sprint-specific release details directly from the UI. The left section lists all release notes, and individual links open the respective `.md` files.  
- **Bigger Chat Box** - The agent chat box has been enhanced to be larger and responsive, improving readability and adapting to available screen space for a better user experience.
