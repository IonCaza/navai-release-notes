**Features Released**
- Agent Cover Image
  - Users can now toggle the visibility of agent cover images to ensure consistent and professional visual presentation. When enabled, agent cards display user-provided or default fallback images. When disabled, all cover images are hidden, providing a simplified layout. This preference applies per user and environment across all views.
- Export Agent Messages to Word
  - Users can now select specific agent responses and export them to a Word document while maintaining the original chat format. This feature supports all chat types and allows for greater control over exported content.

**Additional Enhancements**
- The footer now supports flexible branding options.
  - Users can configure the footer to display both the Accenture logo and a client logo, only one of the logos, or neither. When both logos are displayed, the client logo appears first, separated by a vertical bar.
- Release notes are now accessible via a public URL.
  - Users can view release notes for each sprint through a dedicated section in the UI, which links to a public repository containing the release notes in markdown format.
- The agent chat box is now larger and responsive.
  - The chat box dynamically adjusts to the available screen space, improving readability and user experience.
