**Features Released**
- Agent Cover Image
  - Users can now toggle the display of agent cover images on or off at the user level, ensuring a consistent and customizable layout. When enabled, agent cards display user-provided or default fallback images. When disabled, all cover images are hidden, providing a simplified interface.
- Export Agent Messages to Word
  - Users can select individual agent responses and export them to a Word document while maintaining the original chat format. This feature supports all chat types and allows users to control the content included in the exported file.

**Additional Enhancements**
- The application footer now supports displaying both the Accenture logo and a client-provided logo, offering flexible branding options. Users can choose to display both logos, only one, or none, with a default Accenture logo as a fallback.
- Release notes are now accessible via a public URL, allowing users to view release details directly from the application interface. The release notes are generated and published to a public Git repository at the end of each sprint.
- The agent chat box has been improved to be larger and more responsive, adapting to the available screen space for better usability and enhanced user experience.
