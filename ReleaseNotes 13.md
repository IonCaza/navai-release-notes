**Features Released**
- Clone Entities - Agent  
  - Users can now clone agents and their related entities, such as datasets and system instructions, either by value or reference. The cloning process ensures that datasets are cloned by reference, while system instructions are cloned as new copies owned by the user. A disclaimer in the UI informs users that datasets will not be cloned.  

**Additional Enhancements**
- A preview UI component provides users with a clear overview of the items that will be cloned, including datasets, system prompts, and templates. Editable agent names and detailed notes ensure users are informed about the cloning process and any potential impacts. Errors in retrieving agent or clone data are handled gracefully.
