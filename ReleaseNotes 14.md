**Additional Enhancements**
- Error messages are now localized for global users.
   - Frontend error messages are mapped to localized strings based on backend error codes, ensuring user-friendly and language-specific feedback. Fallback messages are provided for unknown errors, and detailed error information is available for developers in debug views.
- Users can now search for datasets in the Reference Data menu.
   - A text-based search feature has been added to the Reference Data menu, allowing users to quickly locate datasets by name or description. The search applies to both "My Datasets" and "Shared with me" sections.
- Users can now search for system prompts in the System Prompts menu.
   - A text-based search feature has been added to the System Prompts menu, enabling users to efficiently find specific prompts by name or description.
- The "Shared with me" section in the Datasets menu can now be collapsed.
   - Users can collapse the "Shared with me" section in the Reference Data menu, allowing the "My Datasets" section to dynamically expand and improve visibility of personal datasets.
- Provider name is now displayed in the Edit Model flow.
   - When editing an existing model card in the Nav AI registry, the provider name is now displayed in a non-editable text box for better clarity.
