**Additional Enhancements**
- Error messages are now localized for global users.
   - Frontend error messages are mapped to backend error codes and displayed in the user's preferred language. Fallback messages are provided for unknown errors, and detailed error feedback is available in developer consoles.
- Users can now search datasets in the Reference Data menu.
   - A text-based search feature allows users to quickly locate datasets by name or description, improving efficiency when managing large datasets.
- Users can now search system prompts in the System Prompts menu.
   - A text-based search feature enables users to locate specific prompts by name or description, streamlining the process of creating or updating agents.
- The "Shared with me" section in the Datasets menu can now be collapsed.
   - Users can collapse the "Shared with me" section to focus on their own datasets, with the "My Datasets" section dynamically expanding to fill the available space.
- Provider name is now displayed in the Edit Model flow.
   - When editing an existing model, the provider name is shown in a non-editable text box for better clarity.
