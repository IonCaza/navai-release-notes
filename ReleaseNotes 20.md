<div align="center">Upcoming Release Notes for <b>12 January 2026</b></div>
<div align="center">Release Version: <b>Release version 20</b></div>

This communication is to notify users of NAV AI of enhancements made to the application on a biweekly basis.
_Please reference the attachment for additional photos of the features and enhancements._

**Features Released**
- Unified Agents Tab
   - Agents and Assistants are now merged into a single entity, streamlining agent creation and management. All new and migrated agents appear under a unified "Agents" tab, with function tool capabilities integrated directly. The "Utility Agent" tab will be removed in a future release, and users can continue to use previously created utility agents.
- Agent Chat Worksheet
   - Users can now pin valuable agent responses into persistent worksheets, enabling ongoing collaboration and continuity across sessions and teams, even if the original agent or workspace is no longer available.
- Internal User Legal Notices
   - Legal disclaimers now appear for internal users during NAV AI registration, with a link to the Accenture Privacy Statement always visible in the customizable footer component.
- User Communication Banner
   - Administrators can create and manage a user communication banner visible across all screens, ensuring timely delivery of important updates and alerts.
